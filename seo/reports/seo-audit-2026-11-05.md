# Evaluo — SEO P0/P1 audit · 5 November 2026

Scope: GitHub `master` and **Preview only**. No merge/deployment to `main` or production.

## Evidence actually observed

- Google Search Console connected via Windsor.ai: property `sc-domain:evaluoapp.com`. Daily data returned **352 impressions, 10 clicks for 28 Oct–4 Nov 2026**, including preliminary data for Nov 2–4. This is a short post-migration sample, not a monthly trend.
- Page-level observations: `/ia-para-estudiantes` 34 impressions / 0 clicks; `/como-estudiar-ingreso-unlam` 32 / 0; `/uba-xxi/parciales` 14 / 1; `/funciones/crear-mapa-mental-desde-pdf` 10 / 0; the exact requested `/funciones/resumir-pdf-con-ia` and `/estudiar-pdf-con-ia` did not appear in the returned page rows. Do not infer zero lifetime impressions or traffic from absence.
- Sitemap row: `https://evaluoapp.com/sitemap.xml`, 580 URLs submitted, 0 errors, 0 warnings, last downloaded 4 Nov 2026. **Indexed count unknown.** The connector's `indexed` field is deprecated and returned 0; this does *not* establish that zero URLs were indexed.
- Search Console property `evaluo.com.ar` was NOT included in the connected Windsor.ai accounts, so old-vs-new Search Console migration coverage cannot be compared in this audit.
- Bing Webmaster Tools Recommendations, user-connected browser page for `evaluoapp.com`: 3 moderate SEO recommendations, including **two pages flagged for review of important meta robots tags** and a general inbound-link recommendation. The specific flagged URLs were not visible in the accessible view. Do not remove noindex from private or duplicate routes without inspecting those URLs.
- Vercel setting `NEXT_PUBLIC_SITE_URL`: **production already points to `https://evaluoapp.com`**. **Preview was incorrectly set to `https://evaluo.com.ar`**, a concrete potential source of wrong canonical and sitemap hostnames. Fixed **Preview only** to `https://evaluoapp.com` on 5 Nov 2026, and reread both environment settings to verify the new host. Production setting unchanged.
- Source metadata uses `toAbsoluteUrl` and `SITE_URL`; public routes explicitly define index/follow and canonicals. `app/robots.ts` protects private paths and advertises the canonical sitemap.
- The exact HTTP status/location chain from each old-domain URL remains **not independently confirmed** in this audit. The new non-mutating GitHub Action `seo-migration-audit.yml` runs public HTTP checks and stores a structured JSON report, classifying bot challenges as inconclusive.

## P0 Bing Recommendation rule 100 — RESUELTA (05/11/2026)

El usuario abrió en su Bing Webmaster Tools la recomendación **Important pages using meta robots tag that need review** (ruleId=100). La tabla mostró exactamente las siguientes 2 URLs:

- `https://evaluoapp.com/simulador/2a8704a4-b44a-4dce-a478-9a6a603ecdd7/3?acq=preguntero_landing_v1`
- `https://evaluoapp.com/simulador/1f25f0f0-06c6-4cc0-87d4-090c5b5bf3d9/1?acq=preguntero_landing_v1`

**Clasificación:** rutas de práctica interactiva, no landings de adquisición SEO. Código verificado en ambas ramas `main` y `master`: `app/(es)/simulador/[materia_id]/[parcial]/page.tsx`, `generateMetadata()`: cuando existe la materia pública devuelve `robots: { index: false, follow: true }`. Para IDs inexistentes/incorrectos, `robots: { index: false, follow: false }`. No son errores de bloqueo accidental.

**Descubrimiento correcto:** `/pregunteros`, `/pregunteros/[slug]` y `/pregunteros/[slug]/parcial/1|2|integrador` se incluyen en el sitemap, condicionadas a que haya preguntas públicas; **no** se incluyen rutas individuales `/simulador/[uuid]/[parcial]`. Las páginas SEO sirven de entrada orgánica y enlazan al simulador para iniciar la práctica.

**Decisión P0:** NO retirar `noindex`, no incluir las URLs del simulador en el sitemap, no bloquear indiscriminadamente `/simulador` en `robots.txt` (Bing necesita poder rastrear la etiqueta `noindex`). La recomendación del buscador se acepta como aviso informativo sobre URLs que intencionalmente no deben indexarse. Puede seguir visible hasta próximos rastreos o mientras Bing mantenga esta clasificación. **Cerrado como 'no acción necesaria'; sin cambios de código ni de producción.**

Limitación: no se ha realizado una prueba HTTP por página para esos UUID; la decisión está respaldada por la lista de Bing y la comparación de metadatos de `main`/`master`. Ante un cambio futuro de estrategia SEO de simulares, revisar calidad de contenido, URLs canónicas y privacidad antes de modificar `noindex`.
