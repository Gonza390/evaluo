# El Universo de Evalúo

## 1. El Concepto (La Propuesta de Valor)

Evalúo es un acompañante académico inteligente. No es solo una base de datos de materias, es un sistema que "entiende" la carrera del alumno. El objetivo es que el estudiante encuentre TODO su material organizado bajo el programa específico de su Universidad y Facultad.

## 2. El Ciclo de Vida del Usuario

1. **Visitante (Explorador):** Entra a la web para buscar una materia específica (ej: "Derecho Civil 1"). Puede ver el contenido, pero no puede guardar nada. El sistema lo seduce con la organización para que se registre.
2. **Usuario Registrado (Alumno):** Al loguearse, el sistema le pregunta su Universidad y Carrera. A partir de ese momento, la web se transforma: ya no busca en "todo internet", sino en el plan de estudios de SU carrera.
3. **Fidelización:** El usuario marca materias como "Favoritas" o "Finalizadas", construyendo su propio historial académico en su Dashboard.

## 3. El Motor Jerárquico (Cómo se organiza la información)

El sistema es una mamushka de datos que la IA debe respetar siempre:

- **Nivel Superior: Universidad** (Ej: Siglo 21, UBA, UNC).
- **Nivel Medio: Carrera** (Ej: Abogacía, Contador, Psicología).
- **Nivel Base: Materia** (Ej: Economía I, Introducción al Derecho).
- **Nivel Contenido: Módulos/Apuntes** (Lo que el alumno estudia).

## 4. Filosofía de Interfaz (UX/UI)

- **Minimalismo Académico:** La interfaz debe ser limpia, evitando distracciones. El foco es el contenido.
- **Acceso Rápido:** Un alumno siempre debe estar a máximo 2 clics de su materia actual.
- **Estado de Ánimo:** Usar colores que transmitan confianza y orden (verdes, azules oscuros, dorados sutiles).

## 5. Reglas de Oro para la IA

- **No inventar datos:** Si una materia no pertenece a una carrera, no la muestres.
- **Seguridad Silenciosa:** El usuario no debe sentir que el sistema lo bloquea, sino que lo "invita" a participar (ej: el botón de favoritos redirige al login amigablemente).
- **Consistencia:** Mantener siempre el mismo tono profesional y motivador en los mensajes del sistema.
